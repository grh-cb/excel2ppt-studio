# 实施计划（M0–M5）

> 目标：交付一个可运行、可测试、可发布的 Excel→PPT 模板填充工具。
> 主形态：本地 Web 应用（FastAPI + 浏览器四步向导）；附加形态：DSH Cordis 插件封装；发布形态：GitHub 标准仓库。

## 总原则

1. **保真优先**：默认不改变模板任何格式属性；任何"有损优化"必须是显式开关并在报告中标注。
2. **先窄后宽**：首版只做文本/表格/图片；图表、SmartArt、AI 映射后置。
3. **可机检**：每个里程碑都有可自动执行的验收命令，不靠肉眼。
4. **失败可见**：非零退出码 + 中文单行错误；降级路径打 WARNING。
5. **程序化 fixture**：测试样例用代码生成，不提交二进制大文件。

| 交付 | 验收 |
|---|---|

| `excel_images.py`：DISPIMG 提取 | 无 `cellimages.xml` 时报可读错误，不抛裸堆栈 |

| 浮动图片（非 DISPIMG） | 中 | 中 | 提供路径/文件夹/URL 三种源 |
| 大文件内存 | 低 | 中 | 流式生成、媒体去重 |

## 验收总表（可机检）

1. 输出页数 = 有效数据行数 × 每页行数 + 附加页。
2. 每页 shape 集合、坐标 EMU、字号、颜色与模板页逐项相等（文本除外）。
3. 槽位替换率 100%，未替换项在报告中列名。
4. 图片关系可解析、media 存在、宽高比误差 < 0.5%。
5. WPS + PowerPoint 打开无「修复」提示。
6. 1000 行生成 < 60s，内存峰值 < 500MB。
7. `pytest` 全绿；`ruff check` 无错误。
