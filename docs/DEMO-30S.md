# 30 秒演示 GIF · 分镜脚本

> 目标：让人 30 秒内看懂「Excel 台账 → 100 页 PPT，格式不走样」。
> 素材：`2026年工程质量问题台账_v9_最终版.xlsx`（100 行 / 240 图）+ `模板.pptx`（单页）
> 工具：ScreenToGif（免费）或 OBS；输出 1280×720 / 15fps / ≤8MB

## 一、录制前准备（一次性）

| 项 | 设置 |
|---|---|
| 屏幕 | 1920×1080，缩放 100%，隐藏任务栏 |
| Excel | 打开台账，停在「2026质量问题台账」工作表，选中 A1 |
| Studio | 已启动 `e2p web`，停在第一步 |
| 模板 | `模板.pptx` 路径已复制到剪贴板 |
| 鼠标 | 移动放慢，点击后停 0.5 秒再走 |

## 二、分镜（8 个镜头，共 30 秒）

| # | 时间 | 画面 | 操作 | 字幕（大字，底部） |
|---|---|---|---|---|
| 1 | 0–3s | Excel 台账，滚过 100 行、图片列 | 鼠标滚轮向下滚动 3 屏 | **100 行台账，240 张现场照片** |
| 2 | 3–6s | Studio 第一步 | 粘贴模板与 Excel 路径 → 点「读取」 | **选模板和台账** |
| 3 | 6–10s | 第 2 步画布（自动落在正文页） | 点红色标题框 → 下拉选「检查发现问题」 | **点元素，直接选列** |
| 4 | 10–13s | 正文三处映射 | 依次点正文段 → 选「项目名称」「检查发现问题」「整改建议」 | **三处映射，10 秒** |
| 5 | 13–17s | 第 3 步预览 | 翻页：第 1 页 → 第 50 页 → 第 100 页 | **先看效果，再生成** |
| 6 | 17–21s | 第 4 步生成 | 点「生成」，进度条走完（可 2× 加速） | **点一下，16 秒** |
| 7 | 21–26s | WPS 打开成品，翻 3 页 | 翻页，停在有照片的一页 | **100 页，版式和模板一模一样** |
| 8 | 26–30s | 定格：成品页 + 项目名 | 叠一行字：`Excel2PPT Studio · 开源免费` | **Excel 台账 → 汇报 PPT** |

## 三、剪辑要点

1. **掐掉等待**：读取 Excel 约 10 秒、生成约 16 秒，用 2×–4× 加速，只保留首尾。
2. **每镜 3–4 秒**，镜头 3/5/7 各留一个「停顿帧」方便观众看清。
3. 字幕统一放在底部 1/6 处，白字黑边，字号 ≥ 48px。
4. 开头 0.5 秒加一个「问题 → 结果」的闪帧（左：100 行表格 / 右：100 页 PPT），提高完播率。
5. 结尾 1 秒放仓库地址文字（不要二维码，头条会压图）。

## 四、若想直接生成「效果版 GIF」（不录屏）

用已生成的 3 张页面图轮播（`out/demo/gif/gif_p1.png` / `p50` / `p100`）：

```powershell
# 需要 ffmpeg
ffmpeg -y -loop 1 -t 2 -i gif_p1.png -loop 1 -t 2 -i gif_p50.png -loop 1 -t 2 -i gif_p100.png `
  -filter_complex "[0][1][2]concat=n=3:v=1:a=0,scale=1280:-1,split[a][b];[a]palettegen[p];[b][p]paletteuse" `
  -r 12 out/demo/gif/demo.gif
```

只展示「结果」，不展示「操作」，适合放 README 首屏；完整 30 秒仍建议录屏。
