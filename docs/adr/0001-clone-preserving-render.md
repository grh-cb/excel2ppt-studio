# ADR-0001：用「克隆母版页 + 原位替换」实现零漂移

- 状态：已接受
- 日期：2026-11-07
- 决策人：一片风干叶

## 背景

需求是「严格保留模板原有排版、颜色、字体和位置」。现有 `excel2ppt` 技能的做法是**重建页面**：读取数据后用 python-pptx 的 `add_textbox` / `add_picture` 新建元素，坐标写成常量。这带来三个结构性问题：

1. 坐标/字号/颜色是代码常量，换模板必须改代码；
2. 新建元素无法继承模板的字体继承链、主题色、占位符样式；
3. 表格/图片/图表一旦换版式就错位。

## 决策

采用 **OOXML 部件树深拷贝 + 关系重映射 + 只改文本节点** 的路线：

1. 打开模板，定位「母版页」；
2. 对每个数据行，克隆该页：递归复制 `SlidePart` 的关系树（图片、图表、内嵌工作簿），为每个关系分配新 `rId`，并遍历克隆 XML 中所有 `r:id/r:embed/r:link` 做替换；
3. 克隆页复用同一 `slideLayout`，不复制版式树；
4. 只写 `<a:t>` 文本；`a:rPr` / `a:pPr` / `a:xfrm` / `a:tcPr` 一律不写；
5. 生成后做格式指纹校验（归一化 XML 逐 shape 比对）。

## 备选方案

| 方案 | 否决原因 |
|---|---|
| python-pptx 新建元素 | 无法继承模板格式，坐标硬编码 |
| 用 LibreOffice/COM 驱动「查找替换」 | 依赖桌面软件、不可批量、不可测 |
| 只做文本替换（不支持表格/图片） | 覆盖不了检查表/汇报场景 |
| 直接改 XML 字符串（正则） | 容易破坏命名空间与关系，不可维护 |

## 后果

**正面**
- 格式零漂移，模板可自由换，代码不用改；
- 图片/图表/表格结构原样保留；
- 可按 shape 做机检，回归可靠。

**负面 / 代价**
- 必须理解 OPC 关系模型，实现比「新建元素」复杂；
- 克隆页与原页共享 layout，模板改版式会同步影响所有生成页（这是期望行为，但需在文档说明）；
- 图表内嵌工作簿需额外同步，否则「编辑数据」显示旧值（M4 处理）。

## 验证

- 2026-11-07 实测：模板 5 个 shape（文本框/表格/图片/图表），克隆后 shape 数、字号（28pt）、颜色（`C00000`）、坐标（600000, 300000 EMU）完全一致；WPS 导出 PNG 目视无差异。
- 回归测试：`tests/test_renderer.py::test_clone_preserves_geometry`（断言坐标/字号/颜色/数量）。

## 已知坑

- `pptx.parts.slide.SlidePart.slide` 是 `lazyproperty`：替换 `_element` 后必须 `part.__dict__.pop('slide', None)`，否则拿到旧页。
- `SlidePart.rels.get_or_add()` 会重新分配 `rId`，因此必须记录映射并回写 XML，不能假设 `rId` 不变。
